## 🚀 Overview

This web-based application is an early-stage 3D interactive human anatomy explorer. Built using React, Three.js, React Three Fiber, and GSAP, it features a premium dark medical UI and smooth interactive 3D elements. Users can explore different body systems and interact with anatomical models directly in the browser.

## 🌟 Current Features

- **Interactive 3D Anatomy Setup**: A procedural foundation for exploring 3D structures.
- **System Toggles**: Quick views into different organ systems.
- **Information Panel**: On-demand specific information when interacting with anatomy.

## 🛣️ Future Roadmap

- **Custom 3D Model Uploads**: Support for users dragging and dropping their own `.glb` or `.obj` medical scans or organs into the scene.
- **Enhanced Procedural Models**: Replacing procedural shapes with highly detailed, medically accurate anatomical textures and models.
- **Advanced Annotations**: Adding spatial pins and deeper educational metadata.
- **AR / VR Support**: WebXR implementation for exploring anatomy inside virtual reality or augmented reality.
- **User Accounts**: Ability to save bookmarks, learning paths, and custom scenes.

## 🛠️ Technology Stack

- **Framework**: React / Vite
- **3D Engine**: Three.js & React Three Fiber (R3F)
- **Animations**: GSAP
- **Styling**: Vanilla CSS

## 🏃 Running Locally

To run this project locally, clone the repository and execute:

```bash
npm install
npm run dev
```
